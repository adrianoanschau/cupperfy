# Relatórios de etapa

Cada etapa do projeto gera um markdown aqui, explicando o que foi feito, decisões e o que ficou de fora.

## Convenção

| Item | Padrão |
|---|---|
| Nome | `NNN-slug-curto.md` (ex.: `001-arquitetura-documentacao.md`) |
| Quando | Ao fechar a etapa (antes ou junto do commit da etapa) |
| Idioma | Português |
| Conteúdo mínimo | Objetivo · O que foi feito · Decisões · Fora de escopo · Próxima etapa |

Não substitui a documentação de arquitetura em [`docs/`](../docs/) — os relatórios são o **histórico do que aconteceu**; `docs/` é a **fonte da verdade** do desenho atual.
